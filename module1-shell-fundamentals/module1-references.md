# 📚 Module 1 References — Linux & Shell Fundamentals

Curated resources for this module's scope: Linux/shell basics, the prompt, getting help, and your first commands. Free resources are listed first in each category.

⚠️ **Note:** Links can change over time. If any link below is broken, search for the resource by name — these are all well-known, actively maintained resources as of this writing.

## 📺 YouTube Videos & Channels

- **[freeCodeCamp.org — "Linux Crash Course for Beginners"](https://www.youtube.com/c/Freecodecamp)** 🟢 — Full-length, structured crash courses that cover exactly this module's territory (terminal, shell, first commands) at a beginner-friendly pace.
- **[NetworkChuck](https://www.youtube.com/@NetworkChuck)** 🟢 — High-energy, practical Linux/terminal videos that make fundamentals stick through real demos; great for visual learners.
- **[The Linux Foundation (YouTube channel)](https://www.youtube.com/@TheLinuxFoundation)** 🟡 — Official channel with talks and training previews; useful once you want a more "industry" perspective on Linux fundamentals.

## 📖 Official Documentation

- **[GNU Bash Reference Manual](https://www.gnu.org/software/bash/manual/)** 🟢🟡🔴 — The single authoritative reference for Bash itself, from basic invocation to advanced scripting. Bookmark this now — you'll return to it throughout the whole course.
- **[Ubuntu Official Documentation](https://help.ubuntu.com/)** 🟢 — Official Ubuntu docs covering installation, the terminal, and system basics, matching this course's Ubuntu/Debian focus.
- **`man bash` (local)** 🟢 — Run `man bash` in your own terminal for the complete manual page, always available offline and version-matched to your system.

## 📝 Tutorials & Articles

- **[Linux Journey](https://linuxjourney.com/)** 🟢 — A free, beautifully organized set of short lessons that walk from "what is Linux" through the shell, permissions, and beyond — an excellent companion to this module.
- **[ExplainShell.com](https://explainshell.com/)** 🟢🟡 — Paste any shell command and it visually breaks down every flag and argument with an explanation. Fantastic for building the "command anatomy" skill from this module.
- **[tldr-pages project](https://tldr.sh/)** 🟢 — The official site/repo for the `tldr` tool covered in this module; browse example-driven cheat sheets for hundreds of commands, or find install instructions for your platform.

## 🎓 Courses & Learning Portals

- **[freeCodeCamp — Linux curriculum](https://www.freecodecamp.org/news/tag/linux/)** 🟢 — Free, text-based tutorials and courses covering Linux fundamentals, well-suited to complete beginners.
- **[Codecademy — Learn the Command Line](https://www.codecademy.com/learn/learn-the-command-line)** 🟢 — Interactive, browser-based lessons for absolute beginners; a paid track exists but the intro modules are typically free.
- **[Linux Foundation — Introduction to Linux (LFS101x on edX)](https://www.edx.org/)** 🟢🟡 — A free, self-paced, university-style course covering Linux fundamentals in depth, produced by the organization that stewards the Linux kernel itself.

## 🌐 Websites & Interactive Platforms

- **[OverTheWire: Bandit](https://overthewire.org/wargames/bandit/)** 🟢🟡 — A free, gamified wargame where each level teaches a Linux/shell skill by requiring you to SSH in and solve a puzzle. Bandit's early levels are a perfect match for this module's content.
- **[ExplainShell.com](https://explainshell.com/)** 🟢🟡 — (Also listed above.) Use it interactively any time you see an unfamiliar command in the wild.
- **[JSLinux / Copy.sh Linux emulators](https://copy.sh/v86/)** 🟢 — Browser-based Linux environments if you want to poke around a shell before or alongside your main practice environment.

## 📚 Books

- **["The Linux Command Line" by William Shotts](https://linuxcommand.org/tlcl.php)** 🟢🟡🔴 — Free (legally, as a PDF from the author's own site) and widely considered the best beginner-to-intermediate book on this exact subject; covers everything from this module and far beyond.
- **"How Linux Works" by Brian Ward** (No Starch Press) 🟡🔴 — A deeper dive into what's actually happening under the hood once you're past the fundamentals; good for later in the course, not required now.

## 👥 Communities

- **[r/linux4noobs](https://www.reddit.com/r/linux4noobs/)** 🟢 — A welcoming subreddit specifically for beginners; a great place to ask "dumb" questions about exactly the kind of confusion this module addresses.
- **[r/bash](https://www.reddit.com/r/bash/)** 🟡 — Community focused specifically on Bash, useful once you start writing scripts in later modules.
- **[Unix & Linux Stack Exchange](https://unix.stackexchange.com/)** 🟢🟡🔴 — High-quality Q&A for everything from beginner terminal questions to deep system internals; searchable and well-moderated.
- **[Linux Questions Forums](https://www.linuxquestions.org/)** 🟢🟡 — Long-running, beginner-friendly forum organized by distro and topic.
