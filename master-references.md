# Master References: Linux Bash — Zero to Hero

A curated, whole-course reference list. Each module's own references file goes deeper on that module's specific tools — this is the best-of, top-level list for the entire path. ⚠️ Links may move over time; if one is dead, search the resource's name directly.

---

## 📺 YouTube Videos & Channels

- **NetworkChuck** — 🟢 Energetic, beginner-friendly walkthroughs of Linux fundamentals and terminal basics; great for getting motivated early.
- **DistroTube** — 🟡 Deep, practical Linux/shell content aimed at people who want to actually live in the terminal daily.
- **freeCodeCamp.org (Linux/Bash full courses)** — 🟢 Long-form, structured full-course videos that mirror a classroom pace.
- **The Linux Foundation (YouTube)** — 🟡 Official conference talks and training previews, useful once you want production/sysadmin depth.

## 📖 Official Documentation

- **GNU Bash Reference Manual** (gnu.org/software/bash/manual) — 🟡 The single authoritative source for Bash syntax, parameter expansion, and built-ins. Dense but always correct.
- **GNU Coreutils Manual** — 🟢 Official docs for `ls`, `cp`, `mv`, `cat`, and the rest of the everyday toolkit.
- **GNU sed & GNU awk manuals** — 🔴 The definitive reference once you're past the basics and need an obscure flag.
- **OpenSSH documentation** (openssh.com) — 🟡 Authoritative source for `sshd_config` options and key management.
- **Docker official docs** (docs.docker.com) — 🔴 `ENTRYPOINT`, `HEALTHCHECK`, and signal-handling behavior, straight from the source.
- **systemd.timer / systemd.time man pages** — 🔴 Full `OnCalendar=` syntax reference for scheduling.

## 📝 Tutorials & Articles

- **ExplainShell.com** — 🟢 Paste any shell command and get every flag explained inline — invaluable while learning to read other people's one-liners.
- **DigitalOcean Community Tutorials** (Linux/Bash tag) — 🟡 Consistently well-written, practical, sysadmin-focused guides.
- **Bash Hackers Wiki** — 🔴 Deep-dive articles on lesser-known Bash behavior and pitfalls (archived/mirrored in places — search if the primary link is down).
- **"Unofficial Bash Strict Mode"** by Aaron Maxwell — 🔴 The article that popularized `set -euo pipefail` as a default; worth reading once, directly.
- **BashPitfalls (Greg's Wiki)** — 🔴 A running catalog of common Bash scripting mistakes and why they happen.

## 🎓 Courses & Learning Portals

- **Linux Journey** (linuxjourney.com) — 🟢 Free, well-organized, byte-sized lessons — ideal companion for Modules 1-5.
- **freeCodeCamp — Bash Scripting Certification** — 🟡 Free, project-based, reinforces scripting fundamentals through Module 8.
- **OverTheWire: Bandit** — 🟡 A free wargame that teaches Linux command-line skills through progressively harder challenges — genuinely fun.
- **TryHackMe — Linux Fundamentals path** — 🟡 Free tier available; strong for tying security-auditing concepts (Module 18) to hands-on practice.

## 🌐 Websites & Interactive Platforms

- **crontab.guru** — 🟢 Build and sanity-check cron schedule expressions visually — use this every time you write a cron line.
- **regex101.com** — 🟡 Build and test regular expressions with live match highlighting; invaluable for Module 9.
- **ShellCheck.net** — 🔴 Paste a script and get static-analysis warnings instantly, no install required.
- **CIS Benchmarks** (cisecurity.org) — 🔴 Industry-standard hardening checklists for Ubuntu and other distros, referenced throughout Module 16/18.

## 📚 Books

- **"The Linux Command Line"** by William Shotts — 🟢 Free PDF available; the best full-length beginner-to-intermediate book on this exact subject.
- **"Learning the bash Shell"** (O'Reilly) by Cameron Newham — 🟡 A classic, thorough treatment of Bash as a scripting language.
- **"sed & awk"** (O'Reilly) by Dougherty & Robbins — 🔴 The definitive text on both tools, still relevant decades later.
- **"The AWK Programming Language"** by Aho, Kernighan, Weinberger — 🔴 Written by AWK's own creators; short, dense, excellent.

## 👥 Communities

- **r/linux4noobs** and **r/bash** (Reddit) — 🟢 Friendly, active communities for beginner and intermediate questions respectively.
- **Unix & Linux Stack Exchange** — 🟡 The best place to search for (or ask) a specific technical question — searchable history is huge.
- **Server Fault** — 🔴 Stack Exchange's sysadmin/production-operations focused sibling site — great for the production-hardening and monitoring topics.
- **Lynis / fail2ban / OverTheWire Discord & community channels** — 🔴 Tool-specific communities once you're deep into security auditing and hardening.
